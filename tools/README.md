# 像素风小动画装配器（Pixel Scene Builder）

> 游戏生产工具 · 独立产品，不随游戏发布（`tools/` 已被 `.dockerignore` 排除）
> 独立提交：本目录改动单独 commit（`tools: ...`），与游戏本体提交分离

## 是什么

一个浏览器端（零依赖、file:// 直接打开）的**像素风 Web 小动画生成器**：
把任意图片（非 8bit 亦可）转换为像素风素材，在模拟场景画布上**所见即所得地装配**
（位置/大小/透明度/层级/滚动/闪烁/脉动/多帧），调整结果通过**打开/保存 js** 直接
写回场景文件（页面内改写，无需复制粘贴），目标网页刷新即生效。

适用于：为网页/首页/游戏 UI 制作轻量像素氛围动画，而无需手写代码。

## 使用

1. 双击打开 `tools/img2asset.html`（或任意静态服务器）
2. **导入素材**：拖入/选择任意图片 → 调像素化参数（分辨率 / 减色色板 / 量化 / 去背景）→ 重像素化
3. **添加到场景** → 在场景画布上**拖拽移动、拖右下角黄手柄缩放、点击选中**（图层栏自动定位展开对应卡片）
4. 顶部工具栏（**单行**）：**打开 js** + 全局设置（宽 / 高 / 周期 / 背景色，字段名标注）+ 场景层开关 + 播放暂停（靠右）
5. **右侧图层栏**（占满页面高度，**内部滚动**，**跟随时间轴**——显示播放头所在场景的参数值）：元素卡片——头部左侧是 **z 值与展开箭头**，右侧是 **[S]（显示时间弹窗）/[隐藏]/[删除]**；点击卡片=选中并展开参数，**素材卡片为中文说明表单**（滚动速度/平铺周期/方向、动画类型 静态·闪烁·脉动、动画周期、帧数/帧率 + 复制），程序元素为通用参数表单；**每行参数右侧小 [s] 开关**：默认关（改动写常量、作用于所有场景）⇄ 点击开（只改当前场景槽，自动生成按场景数组）；拖拽卡片排序=重排 z 并**同步卡片顺序**；画布点击元素自动定位展开
6. **时间轴**（画布下方，**清晰渲染**：按显示尺寸×2 超采样建后备存储）：0~循环周期秒，点击/拖动跳转；彩色块 = 各元素的 `show` 显示时段（按场景窗口）；打开含 `scenes` 段名声明的 js 后显示**场景段划分**（段底色 + 段名 + 边界拖拽手柄）；红色播放头
7. **场景栏**（画布与时间轴之间，需 js 声明 `scenes`）：**点击 chip = 切编辑场景 + 跳播放头**（当前场景实线高亮）、双击改名、✕ 删除、`+ 场景` 新增；时间轴**边界拖拽**（写 `sceneBorders`）；loop 调整联动钳制；场景数变化自动补齐/截断所有按场景数组
8. **显示时间弹窗**（卡片头 [S]）：每行一个场景——行=开关（亮=显示 / 暗=隐藏），开时下方出现**场景内多段窗口条**（PS 渐变条式：**点击段=切分 / 点击空白=加段 / 拖段体移动 / 拖两端缩放 / 双击删除**；**窗口绝对秒数标注在时间轴上**（0.1s 精度，[S] 面板保持干净），**场景边界拖拽时边界秒数实时显示**）；底层数据为 `show: [null|[[f0,f1],…], …]`（场景内 0~1 比例，边界调整不破坏显示）；旧格式（`{scenes:[..]}`/`[t0,t1]`）自动迁移；[隐藏] = 独立调试层（不碰 scene 可见性，保存写 `hidden:true`）
9. **场景层**（默认**不预设载入**）：初始画布为空白；「打开 js」载入实际场景后，场景层才显示对应画面并**适应视窗**——显示框高度跟随 js 宽高比（载入即占满），**上限 = 视口高 × 2/3**（高比例 js 不会吞掉底部时间轴）；**Alt+滚轮缩放画布内容**（0.2~8×，双击复位，右上角徽标显示倍率），像素化缩放，超出显示框部分裁剪；改高宽/载入/窗口 resize 时显示框自动重算

### 页面内修改（打开 / 保存 js）

- **打开 js**：选择场景文件 → 自动识别：
  - `SCENE`（装配器导出格式）→ 载入画布与元素，继续拖拽/调参
  - `HOME_SCENE` / `DEFAULT_HOME_SCENE`（参数化场景，如 home-scene.js）→ 图层栏生成元素卡片（程序元素点击展开、素材点击选中展开），调整**实时生效**于场景层动画
- **保存 js**（图层栏右上角）：写回原文件（File System Access API；环境不支持则下载替换）——目标页面**刷新即生效**；保存前自动自检（写回文本可重新解析）

> 前提：home-scene.js 已参数化（元素参数集中 `DEFAULT_HOME_SCENE`，运行时优先读 `window.HOME_SCENE`）。
> File System Access API 需 localhost/https 打开工具页；file:// 下自动降级为下载。

## SCENE 格式（装配器保存/导出）

```js
{ w, h, bg, fps, scenes, elements: [{
  name, src: 'data:image/png;base64,...', x, y, w, h,
  alpha, z, hidden,
  scroll: { speed, span, dir },   // speed 像素/秒（0=静态）；span 平铺周期（=宽）；dir left|right
  anim: 'static'|'blink'|'pulse', // blink=透明度闪烁；pulse=大小脉动
  animMs,
  frames, fps,                    // 多帧 sprite sheet（帧表横向裁切）
  show                             // 显示条件：{scenes:[..]} 场景段 或 [t0,t1] 秒区间
}] }
```

`scenes: ["段名", ...]` 为可选字段：声明后时间轴显示场景段划分（段数 = 数组长度）、工具内可增删/改名/拖边界（写 `sceneBorders`）；段内取值用**按场景数组** `key: [v0,v1,…]`（长度=场景数，渲染端 `val()` 自动按场景取数）。`hidden: true` 表示图层栏隐藏该元素（装配与场景层均不绘制）。

## 参数化场景 js 生成规范（SCENE_SPEC）

供「识图/生成类 Agent」在结构参数化时遵循的书面规范：顶层结构、元素 schema、参数类型表、
七条约定（消灭按场景散键 / 声明 scenes / 动态效果显式声明 / 颜色统一 hex 等）与反例正例。
工具打开 js 时按该规范做「规范自检」并提示。详见 **[SCENE_SPEC.md](SCENE_SPEC.md)**。
