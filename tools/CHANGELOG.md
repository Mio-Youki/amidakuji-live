## v1.6 —— 图层栏跟随时间轴 + 单值参数编辑 + 显示时间弹窗（逐场景显隐）
- **图层栏跟随时间轴**：多少套 scene 就有多少套图层栏状态——每行参数**只显示当前场景的一个值**（播放头所在段，`tlScene()`）；播放头跨场景/点击场景 chip（=切编辑场景+跳播放头）自动重建图层栏与高亮当前 chip；移除 v1.5 的多格按场景数组输入与 [S]/[常量] 大按钮
- **参数行小 [s] 开关**（默认关）：关=改动写常量（作用于所有场景）；开=改动只写**当前场景槽**（自动生成/维持按场景数组）；数字/颜色/文本参数统一支持；状态按「卡片|参数路径」记忆
- **显示时间弹窗**（卡片头 [S]，位于 [隐藏] 左侧）：逐场景显隐开关 + **场景内多段窗口条**（PS 渐变条式）——每场景一行轨道：**点击段=切分为两段 / 点击空白=加段（10% 居中）/ 拖段体=移动 / 拖两端手柄=缩放 / 双击段=删除**（220ms 防双击误切）；**窗口绝对秒数标注映射到时间轴**（弹窗元素窗口边界红色小字，0.1s 精度，[S] 面板保持干净）；**场景边界拖拽时显示边界绝对秒数**（红色 `24.0s` 于边界处，0.1s 精度，随拖拽实时更新）；内部存 0~1 比例（场景边界调整不破坏显示）
- **show 统一为按场景窗口数组**：`show: [null | [[f0,f1],…], …]`（null=隐藏；单窗口 `[f0,f1]` 自动归一为列表；f 为场景内 0~1 比例）；legacy 格式自动迁移（`{scenes:[..]}`/`[t0,t1]`/`hidden` 布尔 → 窗口数组，`migrateShow`）；[隐藏] 按钮 = 全局隐藏/恢复快捷（写入 show 全 null / 删除）
- **修复**：
  - **[S] 时间轴联动跨面板混显**：新增 `showFocusEl`——时间轴**只映射当前/最近打开的 [S] 面板元素**（色块 + 窗口秒标注），打开另一个面板时旧元素标注消失，不再多色混显；未打开过任何 [S] 时仍显示全部元素
  - **moon 场景1不可见**：原 home-scene 硬编码 `moon(part) { if (part === 1) return; }`（雾幕阶段不画月亮）无配置可调——已参数化：移除硬编码，默认配置补 `moon.show: [[[0,1]], null, [[0,1]], [[0,1]]]`（默认视觉不变，[S] 弹窗可调）
  - **全局高宽修改裁剪/黑边**：根因是 home-scene 画布在 `init()` 时固定 320×118，改 cfg.w/h 后与 stage 画布（已跟随）尺寸错位；新增 `HomeScene.resize()`（后备存储 = CFG.w×CFG.h，与 stage 对齐），gw/gh 修改与载入场景时调用——画面按背景色铺满新尺寸，无黑边、无裁剪
  - **重导入尺寸不生效**：`resize()` 读模块级 `CFG`，重导入时 `window.HOME_SCENE` 换新对象但 `CFG` 要等下一帧 `syncCfg` 才更新 → resize 用了旧值（面板显示 320×150、画布仍是 118）——修复：`resize()` 开头先 `syncCfg()`，重导入即时生效（DIAG 验证 canvas=320×150）
  - **初始不预设场景**：工具启动不再显示 home-scene 默认动画（`#home-scene` 默认隐藏、场景层勾选默认关、`showScene=false`）——载入实际 js 后场景层才显示对应画面并适应视窗
  - **显示框高度跟随 js 宽高比（封顶）**：`.stage-wrap` 高度由 JS 计算 = 容器宽 × cfg.h/cfg.w（载入即占满显示框），**上限 = 视口高 × 2/3**（`resizeStageWrap`）——高比例 js 不会吞掉底部时间轴/场景栏；gw/gh 修改、载入/装配、窗口 resize 时重算
  - **画布内容缩放（Alt+滚轮）**：`state.zoom`（0.2~8×，Alt+滚轮步进 ×1.1，双击画布复位）；双画布改为 JS 显式尺寸（fit × zoom，`applyCanvasDisplay`），`image-rendering: pixelated` 像素化缩放——zoomed 超出显示框部分被容器裁剪（`overflow: hidden`），右上角黄色缩放徽标（×1.1，双击复位）；`stagePos` 指针映射基于内容框
  - **固定显示框 + 等比缩放**：`.stage-wrap` 改为固定尺寸（宽 100% + 高 218px，**不再被 cfg.h 撑开**），双画布 `object-fit: contain; object-position: left top`——画布内容按 cfg.w:cfg.h 等比缩放 fit：动画整体缩小而非裁剪；比例比默认更高 → **右侧留空**（坐标定位下的新空间）；更宽 → 底部留空；`stagePos` 指针映射同步改为 contain 换算
- **修复**：bar 点击无响应——默认整段 `[0,1]` 占满轨道使「点空白加段」永远落在段内被吞掉；改为**点击段=切分**保证任何点击都有响应；另修 `normShowWindows` 无 show 时各场景共享同一数组引用的隐患
- **渲染端**：home-scene `elShown` 支持窗口数组（按场景边界取场景内时间），`sceneBounds` 辅助；工具时间轴 `showRanges` 按窗口逐段画色块
- **生成规范简化**（SCENE_SPEC v2）：Agent 生成只需**常量参数** + show 窗口数组（或省略=全程）；按场景数组由工具按需生成；legacy 兼容保留
- **修复**：
  - **[隐藏] 独立为「调试隐藏」**：只切换元素 `hidden`（全局覆盖，**不触碰 show 窗口**——避免"恢复后 scene 全激活"丢信息）；按钮随状态显示 隐藏/显示；保存时仍隐藏则写最外层 `hidden:true`（装配模式 `buildExportText` 同步补 hidden 字段）；`migrateShow` 不再折叠 hidden
  - **[S] 弹窗真正影响画布**：根因是 home-scene 图层表仅 fog/signal/bridge 尊重 `elShown`——现**所有程序元素**统一包裹 `elShown` 检查（show 窗口对每个元素生效）
  - **暂停时修改不同步**：新增 `refreshStage()`（renderStage + renderTimeline + `HomeScene.seek(t)` 强制场景层重绘一帧），walkForm/imgForm 全部编辑、[隐藏]、[S] 弹窗、画布拖拽结束（pointerup）均调用——暂停态改动立即可见
  - **导入识别场景专属参数**：数值/颜色**按场景数组在导入时自动激活 [s]**（`rowS` 初始化），显示当前场景值且编辑只写当前槽，不破坏数组；常量参数 [s] 默认置灰
- 场景 chip 样式区分：active=实线黄框，`+ 场景`=虚线置灰（不再误读为激活）

## v1.5 —— 参数轨道 + 场景内建编辑 + 生成规范（概念层落地）
- **参数轨道模型**（替代按场景散键）：数值/颜色参数三态——常量 number ↔ **按场景数组** `[v0,v1,…]`（长度=场景数）↔ 关键帧 `{t,v}`（预留 PLAN P1）。渲染端统一取值 `val(e,k,t)`/`valAt(e,k,part)`（常量→自身；数组→按 scene(t) 取，长度不足取末位）；home-scene.js 全量迁移（moon 的 `x/x3/y/y2/y3`、clouds 的 `speed1/color1`、mountains 的 `speed2/peak2/color3/fill2a/fill2b`、train 的 `beamLenFog/beamFog` 等 → 按场景数组），**视觉与行为不变**
- **场景内建编辑**：`scenes` 声明后，画布与时间轴之间出现**场景栏**——场景 chip 点击改名 / ✕ 删除 / `+ 场景` 新增（等分插入）；**时间轴边界拖拽**（顶部三角手柄，±6px 命中，写 `sceneBorders`，非均匀段正确显示）；loop 调整联动钳制边界；场景数变化自动**补齐/截断所有按场景数组**（`syncSceneArrays`）；`show:{scenes}` 区间按实际边界计算
- **按场景数组编辑**：walkForm/imgForm 中长度=场景数的数值/颜色/rgba 数组 → **每场景一个输入框**（title 标注场景名）+ [常量] 合并按钮；常量行带 **[S] 拆分按钮**（一键转按场景数组）
- **生成规范**：新增 `tools/SCENE_SPEC.md`（顶层结构/元素 schema/参数类型表/七条约定/反例正例）；工具打开 js 时**规范自检**（`checkSceneSpec`）——按场景散键（`x3` 且存在 `x`）、数值数组长度≠场景数（只读）、`show:{scenes}` 未声明 `scenes`，提示于 m-stage/m-props
- **动态场景判定**：home-scene `scene(t)` 优先 `sceneBorders` 否则按 scenes 数等分（兜底 4 段）；loop 每帧读 `CFG.loop`（此前 `LOOP` 常量在加载时固化，改 loop 不生效的隐患一并修复）
- **拖拽重排 = 换 z + 换卡片顺序**（v1.4 延续）：程序元素按键顺序 in-place 重插、素材按新序 splice，卡片顺序与 z 一致并随保存写回
- 修复：`delElement`/`dupElement` 重复定义清理（v1.4 遗留）

- **布局**：场景文件按钮（打开 js / 保存 js）与全局设置合并为画布**顶部工具栏**（sf-row），右侧面板只剩**图层栏**（元素卡片）——全局参数 = js 全局配置，归位到顶部；**字段名保留**（宽/高/周期/背景 逐一标注，一行排列）

- **画布点击联动**：点击画布可编辑元素 → 图层栏**自动滚动定位**到对应卡片并展开（`focusLayerCard` + `scrollIntoView`）
- **卡片头部重构**：**z 值与展开箭头移到左侧**（⠿ z值 ▾ 名称……），右侧新增**[隐藏/显示] 与 [删除] 按钮**（所有元素卡片，含程序化元素）——隐藏置灰卡片（`.layer-card.hid`）、装配/场景层均跳过绘制（home-scene.js 图层过滤 `hidden`）；程序元素删除需确认（保存后场景不再绘制），且 home-scene.js 图层表对已删除元素容错（`CFG.x && {...}` 守卫）

- **素材参数改为卡片展开项**：不再常驻属性面板——素材卡片**点击选中即展开**（再点收起），展开项含全部参数（含 scroll/anim/show）+ 复制；程序化元素卡片点击展开调参；画布点击元素同样触发选中展开
- **时间轴通用化 + 保留 SCENE 划分**：默认/无 scenes 的 js 为**通用中性轨道**（浅色底 + 均匀刻度 + 秒数 + 红色播放头 + show 时段彩色块，非像素风，适合作为通用工具的初始态）；打开含 `scenes:["段名",...]` 的 js（home-scene.js 已补 `scenes` 字段）后**保留场景段划分**——段底色 + 段名标注；`show:{scenes:[..]}` 的段长按 `loop/段数` 计算；高度降至 16px
- **素材卡片选中高亮**（`.layer-card.sel` 边框）；空场景显示空态提示
- **时间轴清晰化**：画布按「CSS 尺寸 × supersample(≥2 或 devicePixelRatio)」建后备存储 + `setTransform` 按 CSS 像素绘制——拉伸/高分屏不再插值放大发虚；高度 20px、刻度字 9px、段名字 9px（红色播放头）
- **图层栏内部滚动**：`#cfgform` 改 `flex:1 1 0 + height:0`（基准 0，不再被内容撑开）+ 显式滚动条样式（`::-webkit-scrollbar`/`scrollbar-width`）——展开多个卡片时**页面高度不变**，列表内部滚动
- **素材卡片表单中文说明（回调上一版本）**：滚动速度（像素/秒）/平铺周期/滚动方向（向左·向右）、动画类型（**静态/闪烁/脉动** 下拉）、动画周期（毫秒）、帧数/帧率（多帧说明）、显示时间（**空=全程 · 0,2=场景段 · 5-20=秒区间**，可编辑回写 `show`）——替换通用 walkForm 的裸字段
- **拖拽重排 = 换 z + 换卡片顺序**：`reorderLayers` 在重排 z 的同时**物理重排卡片**——程序元素按键顺序 in-place 重插（保持 cfg 对象引用，保存写回新顺序）、素材按新序 splice 原数组（装配模式 state.elements 同数组随之更新）；卡片上下顺序与 z 一致
- 顶部工具栏压缩为**单行**（nowrap + 紧凑间距 + 字段名标注），[播放/暂停] `margin-left:auto` 靠右
- 修复：`escapeHtml` 缺失导致图层栏渲染抛错（卡片名转义补全）；`delElement`/`dupElement` 重复定义清理
